## 🔍 RSSistant

This Telegram bot allows users to browse categorized RSS feeds and filter articles by keywords.

### ⚙️ Features
- Browse feeds by category
- Filter articles by keywords
- Inline keyboard UI
- Persistent user filters

### 🛠️ Setup

```bash
git clone https://github.com/yourusername/rss-telegram-bot.git
cd rss-telegram-bot
pip install -r requirements.txt
touch .env 
cat > .env
# Type in the token:
BOT_TOKEN='1234567890qwerty'
# Press Ctrl + D to save and exit
python -m bot.main
```
